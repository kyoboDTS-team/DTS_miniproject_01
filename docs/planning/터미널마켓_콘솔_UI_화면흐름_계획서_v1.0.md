# TERMINAL MARKET 콘솔 UI / 화면 흐름 계획서 v1.0

> **목적**  
> 콘솔 환경에서 화면 전환이 자연스럽고, 팀원이 같은 기준으로 메뉴를 구현할 수 있도록 화면 규칙과 대표 화면을 통일한다.

## 1. 문서 사용 기준

- **Markdown 파일**: 실제 콘솔 화면을 가장 정확하게 보고 복붙하기 위한 개발 기준 문서
- **Word 파일**: Google Drive 공유, 보고, 회의용 정리 문서
- 실제 구현에서는 화면 단위 전환 시 `ClearScreen()`을 사용하고, 같은 작업 안에서 연속 입력 중에는 화면을 지우지 않는다.

---

## 2. 공통 UI 원칙

1. 상단에는 `TERMINAL MARKET` 헤더를 고정한다.
2. 이메일, 장바구니 수량처럼 길이가 달라지는 정보 줄은 **좌우 테두리를 열어 둔다**.
3. 메뉴는 `상품 / 마이페이지 / 시스템`처럼 영역을 묶어 시각적으로 구분한다.
4. 선택 번호는 `01`, `02` 형식으로 통일한다.
5. 실제 구매는 상품 상세가 아니라 **장바구니의 구매하기**에서 시작한다.
6. `SELLING`, `STOPPED`, `AVAILABLE`, `SOLD` 등 DB 상태값은 화면에서도 동일한 용어를 사용한다.
7. 한 작업에서 여러 값을 입력하는 화면은 입력이 끝날 때까지 Clear하지 않는다.

---

## 3. ClearScreen 적용 규칙

### 화면을 지우는 경우

- 메인 메뉴 → 상품 조회
- 상품 목록 → 상품 상세
- 상품 상세 → 장바구니
- 장바구니 → 주문 확인
- 주문 완료 → 메인 메뉴
- Guest / Member / Admin 역할 화면 전환
- 관리자 메인 → 상품 / 재고 / 회원 / 주문 관리 화면

### 화면을 지우지 않는 경우

- 회원가입에서 이메일 → 비밀번호 → 이름 → 연락처 입력
- 상품 등록에서 코드 → 상품명 → 카테고리 → 가격 입력
- 재고 입고에서 상품 → 수량 → 사유 입력
- 장바구니 수량 변경 중
- 주문 최종 확인 입력 중

> **팀 규칙:** `페이지가 바뀌면 Clear`, `같은 페이지에서 연속 입력이면 유지`.

# 5. 상품 조회 흐름

```text
메인 메뉴
   ↓
전체 상품 조회 / 조건 검색
   ↓
상품 목록
   ↓
상품 선택
   ↓
상품 상세
   ↓
장바구니 담기
```

## 5.1 상품 전체 조회

```text
┌─ PRODUCT / ALL ──────────────────────────────┐
│  전체 상품                                   │
└──────────────────────────────────────────────┘

번호  코드     상품명              가격         재고
──────────────────────────────────────────────────
01    ST001    검정 볼펜 0.5mm       1,000원       48
02    ST002    A5 줄노트              2,500원       28
03    TY001    퍼즐 500pcs           12,000원       14
04    EL001    스마트폰 A           900,000원        2
05    EL002    노트북 B           1,500,000원        1
──────────────────────────────────────────────────

상품 번호를 입력하면 상세 정보를 확인합니다.
[0] 이전

선택 >
```

## 5.2 상품 조건 검색

```text
┌─ PRODUCT / SEARCH ───────────────────────────┐
│  상품 조건 검색                              │
└──────────────────────────────────────────────┘

카테고리 코드 > C310
최소 가격      > 500000
최대 가격      > 1000000

검색 결과
──────────────────────────────────────────────────
번호  코드     상품명              가격         재고
01    EL001    스마트폰 A           900,000원        2
──────────────────────────────────────────────────

[1] 스마트폰 A
[0] 이전

선택 >
```

## 5.3 상품 상세 / 장바구니 연결

```text
┌─ PRODUCT / DETAIL ───────────────────────────┐
│  EL001                                      │
└──────────────────────────────────────────────┘

상품명        스마트폰 A
카테고리      스마트폰
가격          900,000원
현재 재고     2
판매 상태     SELLING
시리얼 관리   YES

────────────────────────────────────────────────
[1] 장바구니 담기
[0] 이전

선택 > 1
수량 > 1

장바구니에 추가되었습니다.  현재 장바구니 (4)

[1] 상품 목록으로
[2] 장바구니 보기
[0] 메인 메뉴
선택 >
```

### 구현 규칙

- 전체 조회와 조건 조회는 모두 같은 상품 상세 화면으로 연결한다.
- 상품 상세에서는 **장바구니 담기까지만** 처리한다.
- 장바구니 담기 시 DB 재고를 차감하지 않는다.
- `stock_quantity = 0` 또는 `sale_status = STOPPED`이면 장바구니 추가를 막는다.

# 6. 장바구니 / 구매

## 6.1 장바구니

```text
┌─ CART ───────────────────────────────────────┐
│  총 수량 3                         14,000원  │
└──────────────────────────────────────────────┘

번호  상품명              단가       수량       금액
──────────────────────────────────────────────────
01    검정 볼펜 0.5mm       1,000        2        2,000
02    퍼즐 500pcs          12,000        1       12,000
──────────────────────────────────────────────────
                                      합계 14,000원

[1] 수량 변경
[2] 품목 삭제
[3] 전체 비우기

[4] 구매하기
[0] 이전

선택 >
```

## 6.2 주문 확인

```text
┌─ CHECKOUT ───────────────────────────────────┐
│  주문 확인                                   │
└──────────────────────────────────────────────┘

검정 볼펜 0.5mm       1,000원 × 2       2,000원
퍼즐 500pcs          12,000원 × 1      12,000원
────────────────────────────────────────────────
총 수량                                      3
주문 금액                               14,000원
────────────────────────────────────────────────

주문하시겠습니까?
[Y] 주문 확정
[N] 취소

선택 >
```

### 구매 시점 규칙

- 구매 버튼을 누른 시점에 최신 가격, 판매 상태, 재고를 다시 확인한다.
- 회원 주문은 로그인 세션의 `customer_id`를 사용한다.
- 비회원 주문은 `customer_id = NULL`로 생성한다.
- 주문 성공 시 장바구니를 비운다.
- 주문 실패 시 장바구니는 유지한다.

## 6.3 주문 성공

```text
┌─ ORDER COMPLETE ─────────────────────────────┐
│                                              │
│                 주문 완료                    │
│                                              │
├──────────────────────────────────────────────┤
  주문번호  TM-20260920-A8K3Q7P2
  주문금액  14,000원
└──────────────────────────────────────────────┘

주문이 정상적으로 완료되었습니다.
비회원은 주문 조회를 위해 주문번호를 보관해 주세요.

Enter를 누르면 메인으로 이동합니다.
```

# 7. 연속 입력 화면

## 7.1 회원가입

```text
┌─ SIGN UP ────────────────────────────────────┐
│  회원가입                                    │
└──────────────────────────────────────────────┘

이메일           > user@example.com
비밀번호         > ************
비밀번호 확인    > ************
이름             > 홍길동
연락처           > 01012345678

────────────────────────────────────────────────
입력한 정보로 가입하시겠습니까? (Y/N)
선택 >
```

**화면 전환 규칙**
- 회원가입 진입 시 1회 Clear
- 입력 과정에서는 Clear하지 않음
- 가입 성공 / 취소 후 이전 메뉴로 이동할 때 Clear

## 7.2 관리자 상품 등록

```text
┌─ ADMIN / PRODUCT REGISTER ───────────────────┐
│  신규 상품 등록                              │
└──────────────────────────────────────────────┘

상품 코드        > ST003
상품명           > 빨간 볼펜 0.5mm
카테고리 코드    > C110
가격             > 1200
안전재고         > 10
시리얼 관리      > N

────────────────────────────────────────────────
입력한 상품을 등록하시겠습니까? (Y/N)
선택 >
```

## 7.3 관리자 재고 입고

```text
┌─ ADMIN / STOCK RECEIVE ──────────────────────┐
│  재고 입고                                   │
└──────────────────────────────────────────────┘

상품 코드        > ST003
현재 재고        : 0
입고 수량        > 50
입고 사유        > 초기 입고

────────────────────────────────────────────────
처리 후 예상 재고 : 50
입고 처리하시겠습니까? (Y/N)
선택 >
```

연속 입력 화면은 사용자가 방금 입력한 값을 확인할 수 있도록 이전 입력을 화면에 유지한다.

# 9. 팀 구현 시 통일할 문구

| 상황 | 권장 문구 |
|---|---|
| 입력 오류 | `올바른 값을 입력해 주세요.` |
| 없는 상품 | `존재하지 않는 상품입니다.` |
| 품절 | `현재 품절된 상품입니다.` |
| 판매중지 | `현재 판매하지 않는 상품입니다.` |
| 장바구니 성공 | `장바구니에 추가되었습니다.` |
| 빈 장바구니 | `장바구니가 비어있습니다.` |
| 주문 성공 | `주문이 정상적으로 완료되었습니다.` |
| 처리 취소 | `작업이 취소되었습니다.` |
| 이전 | `[0] 이전` 또는 `[0] 메인 메뉴` |

# 10. 최종 구현 방향

- UI는 화려한 ASCII Art보다 **간결한 터미널 인터페이스**를 목표로 한다.
- 헤더와 화면명은 박스로 강조하되, 사용자 정보처럼 길이가 변하는 부분은 좌우를 열어 둔다.
- 화면 전환은 ClearScreen으로 페이지 단위로 처리한다.
- 연속 입력은 현재 화면에 누적하여 사용자가 입력 내역을 확인할 수 있게 한다.
- 모든 팀원이 동일한 Menu / Detail / Confirm / Complete 패턴을 사용한다.
