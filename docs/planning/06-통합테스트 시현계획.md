## 시연 권장 순서
1. 최초 실행 메뉴와 장바구니(0) 확인
2. 비회원 상품 조건 조회 → 장바구니 → 비회원 주문 → 주문번호 조회
3. 회원가입: 이메일 중복/비밀번호 오류 1회 시연 후 정상 가입
4. 회원 로그인 → 장바구니 → 주문 → 내 주문 조회
5. 관리자 로그인 → 전자제품 상품/시리얼 등록 → 재고 확인
6. 시리얼 상품 주문 및 주문 상세의 시리얼 확인
7. 전체 반품 → 재고와 시리얼 복구 → 재반품 거절
8. 통계에서 반품 주문 제외 확인
9. CSV 정상/오류 파일 처리
