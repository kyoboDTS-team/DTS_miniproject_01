# 🎨 TERMINAL MARKET 콘솔 색상 가이드

> **핵심 규칙**
>
> - `CYAN` = UI / 이동 / 강조
> - `GREEN` = 성공 / 정상 상태
> - `YELLOW` = 주의 / 장바구니 / 확인 필요
> - `RED` = 오류 / 사용 불가 / 실패
> - 일반 텍스트와 테두리는 기본 콘솔 색상 유지

---

# 1. 기본 팔레트

| 용도 | 색상 | ANSI 코드 | 사용 의미 |
| :--- | :--- | :---: | :--- |
| 브랜드 / 강조 | **CYAN 청록** | `36` | 제목, 메뉴 번호, 입력 프롬프트 |
| 정상 / 성공 | **GREEN 초록** | `32` | SELLING, 성공 메시지 |
| 주의 / 장바구니 | **YELLOW 노랑** | `33` | 장바구니 수량, 경고, 확인 필요 |
| 오류 / 위험 | **RED 빨강** | `31` | STOPPED, 품절, 오류 |
| 일반 정보 | **기본색** | `RESET` | 본문, 상품명, 설명, 테두리 |

> 색상은 4~5개 이상 늘리지 않는 것을 권장합니다.

---

# 2. 공통 헤더

기본 화면:

```text
┌──────────────────────────────────────────────┐
│  TERMINAL MARKET                     v1.0    │
├──────────────────────────────────────────────┤
  회원  user@example.com
  장바구니  (3)
└──────────────────────────────────────────────┘
```

## 색상 적용

```text
TERMINAL MARKET     → CYAN

회원
user@example.com    → CYAN 또는 기본색

장바구니
(3)                 → YELLOW

테두리
┌ ─ │ └             → 기본색
```

테두리까지 색상을 넣으면 화면이 과하게 보일 수 있으므로 기본색을 유지합니다.

---

# 3. 메인 메뉴

```text
상품
──────────────────────────────────────────

01  전체 상품 조회
02  상품 조건 검색
03  장바구니                         [ 3 ]
```

## 색상 규칙

- `상품`, `마이페이지`, `시스템` → **CYAN**
- `01`, `02`, `03` 등 메뉴 번호 → **CYAN**
- 메뉴 이름 → 기본색
- 장바구니 `[ 3 ]` → **YELLOW**

예:

```text
상품                         ← CYAN
──────────────────────────

01                           ← CYAN
전체 상품 조회               ← 기본색

02                           ← CYAN
상품 조건 검색               ← 기본색

03                           ← CYAN
장바구니                     ← 기본색
[ 3 ]                        ← YELLOW
```

---

# 4. 입력 프롬프트

모든 화면의 입력 프롬프트는 하나의 규칙으로 통일합니다.

```text
선택 >
```

## 색상

```text
선택 >      → CYAN
사용자 입력 → 기본색
```

회원가입 및 관리자 입력 화면도 동일합니다.

```text
Email >
Password >
Name >
Phone >

상품 코드 >
가격 >
수량 >
```

필드명과 `>` 부분을 **CYAN**으로 사용합니다.

---

# 5. 상품 목록

```text
No   Code    Product              Price      Stock
────────────────────────────────────────────────
01   ST001   검정 볼펜 0.5mm       1,000        48
02   ST002   A5 줄노트              2,500        28
```

## 색상 규칙

- `No / Code / Product / Price / Stock` → **CYAN**
- 상품 번호 `01`, `02` → **CYAN**
- 상품명 / 상품코드 / 가격 → 기본색
- 정상 재고 → 기본색
- 안전재고 이하 → **YELLOW**
- 재고 0 → **RED**

예:

```text
Stock 48    → 기본색
Stock 5     → YELLOW
Stock 0     → RED
```

---

# 6. 상품 상세

```text
상품명       스마트폰 A
Category     스마트폰
Price        900,000원
Stock        2
Status       ● SELLING
Serial       YES
```

## 색상 규칙

필드명:

```text
상품명
Category
Price
Stock
Status
Serial
```

→ **CYAN**

실제 값은 기본색으로 표시합니다.

### 판매 상태

```text
● SELLING   → GREEN
● STOPPED   → RED
● SOLD OUT  → RED
```

### Serial

```text
Serial YES
Serial NO
```

시리얼 여부 자체는 기본색으로 표시합니다.

---

# 7. 장바구니

```text
┌─ CART ─────────────────────────────────────┐
│  3 items                          ₩14,000  │
└────────────────────────────────────────────┘
```

## 색상 규칙

- `CART` → **CYAN**
- 장바구니 총 수량 → **YELLOW**
- 총 금액 → **YELLOW**
- 상품명 / 가격 / 수량 → 기본색
- `TOTAL` 및 최종 금액 → **YELLOW**

예:

```text
TOTAL  ₩14,000
```

→ **YELLOW**

---

# 8. 구매 확인

```text
주문하시겠습니까?

[Y] 주문 확정
[N] 취소
```

## 색상 규칙

```text
[Y] → GREEN
[N] → RED
```

설명 문구는 기본색으로 유지합니다.

이 규칙은 다른 확인 화면에도 동일하게 적용할 수 있습니다.

```text
[Y] 확인 → GREEN
[N] 취소 → RED
```

---

# 9. 주문 성공

```text
ORDER COMPLETE
      ✓
```

## 색상 규칙

```text
ORDER COMPLETE              → GREEN
✓                           → GREEN
주문이 정상적으로 완료되었습니다. → GREEN
```

비회원 주문번호는 중요한 조회 키이므로 **CYAN**으로 강조합니다.

```text
주문번호
TM-20260918-A8K3Q7P2
```

```text
TM-20260918-A8K3Q7P2 → CYAN
```

---

# 10. 성공 메시지

성공 메시지는 모두 **GREEN**으로 통일합니다.

```text
상품이 등록되었습니다.
회원가입이 완료되었습니다.
로그인되었습니다.
재고 입고가 완료되었습니다.
주문이 완료되었습니다.
반품이 완료되었습니다.
수정이 완료되었습니다.
```

→ **GREEN**

---

# 11. 오류 메시지

업무 수행이 불가능하거나 실패한 경우 **RED**를 사용합니다.

```text
존재하지 않는 상품입니다.
재고가 부족합니다.
이미 사용 중인 이메일입니다.
잘못된 비밀번호입니다.
판매 중지된 상품입니다.
이미 반품된 주문입니다.
```

→ **RED**

> SQL Exception 원문이나 DB 접속 정보는 사용자 화면에 직접 출력하지 않습니다.

---

# 12. 주의 / 안내 메시지

실패까지는 아니지만 사용자가 확인해야 하는 메시지는 **YELLOW**를 사용합니다.

```text
재고가 안전재고 이하입니다.
주문번호를 반드시 보관해 주세요.
정말 삭제하시겠습니까?
가격이 변경되었습니다.
현재 재고가 부족해질 수 있습니다.
```

→ **YELLOW**

즉:

```text
GREEN  = 성공
YELLOW = 주의
RED    = 실패 / 금지
```

로 통일합니다.

---

# 13. 관리자 메뉴

```text
┌─ TERMINAL MARKET / ADMIN ──────────────────┐
```

## 색상 규칙

```text
TERMINAL MARKET → CYAN
ADMIN           → YELLOW
```

관리자 메뉴 번호:

```text
01 Product / Category
02 Stock / Serial
03 Customer
04 Order / Return
```

`01`, `02`, `03`, `04` → **CYAN**

관리자 화면도 일반 사용자 화면과 동일한 색상 체계를 유지합니다.

---

# 14. 재고 관리

```text
현재 재고      45
안전 재고      10
```

## 상태별 색상

```text
현재 재고 45
→ 기본색

현재 재고 8
안전 재고 10
→ YELLOW

현재 재고 0
→ RED
```

입고 성공:

```text
+10 입고 완료
```

→ **GREEN**

재고 감소 / 조정:

```text
-3 재고 조정
```

→ 기본색 또는 상황에 따라 **YELLOW**

---

# 15. 시리얼 관리

```text
SM-A-0001     AVAILABLE
SM-A-0002     SOLD
```

## 색상 규칙

```text
AVAILABLE → GREEN
SOLD      → RED
```

시리얼 번호 자체는 기본색으로 유지합니다.

---

# 16. 주문 상태 / 반품 상태

현재 주문 상태:

```text
CONFIRMED
RETURNED
```

색상:

```text
CONFIRMED → GREEN
RETURNED  → YELLOW
```

`RETURNED`는 정상적으로 완료된 반품 상태이므로 RED보다 YELLOW가 적합합니다.

실행 오류:

```text
이미 반품된 주문입니다.
```

→ **RED**

---

# 17. 회원가입 / 연속 입력 화면

연속 입력 화면에서는 과도한 색상을 사용하지 않습니다.

```text
Email >
Password >
Password Confirm >
Name >
Phone >
```

입력 필드명 → **CYAN**

### 검증 메시지

```text
사용 가능한 이메일입니다.
```

→ **GREEN**

```text
이미 사용 중인 이메일입니다.
```

→ **RED**

```text
비밀번호는 8~20자이며...
```

→ **YELLOW**

연속 입력 중에는 ClearScreen을 실행하지 않고 한 화면에서 계속 진행합니다.

# 20. 팀 공통 규칙

팀원별 화면 구현 시 아래 기준을 반드시 동일하게 적용합니다.

```text
CYAN
→ UI / 메뉴 / 이동 / 입력

GREEN
→ 성공 / 정상 상태

YELLOW
→ 주의 / 장바구니 / 반품 완료 상태

RED
→ 오류 / 실패 / 사용 불가

기본색
→ 상품명 / 설명 / 일반 정보 / 테두리
```

## 핵심 원칙

> 색상은 꾸미기 목적뿐 아니라 상태를 전달하는 역할로 사용합니다.

예:

```text
SELLING     → GREEN
STOPPED     → RED

AVAILABLE   → GREEN
SOLD        → RED

CONFIRMED   → GREEN
RETURNED    → YELLOW

정상 재고    → 기본색
안전재고 이하 → YELLOW
품절         → RED
```

이 규칙을 모든 메뉴에서 동일하게 적용하면 각 팀원이 서로 다른 기능을 구현해도 전체 프로그램이 하나의 UI처럼 보이게 됩니다.
