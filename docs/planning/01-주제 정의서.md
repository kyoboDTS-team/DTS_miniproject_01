# 터미널마켓 상품·주문 관리 시스템 - 주제 정의서 v0.3

## 프로젝트 정의
콘솔 Java + JDBC 기반의 미니 마켓 시스템으로, 비회원·회원·관리자 세 역할을 구분한다. 문구·완구·전자제품·명품 상품을 조회하고 장바구니에서 주문한다. 전자제품/명품 등 일부 상품은 개별 시리얼 번호까지 추적한다.

## 사용자
- 비회원: 상품 조회, 카테고리/가격 조건 조회, 장바구니, 비회원 주문, 주문번호 조회, 로그인, 회원가입
- 회원: 비회원 기능 + 내 주문 조회, 본인 주문 반품, 내 정보 수정
- 관리자: 상품·카테고리·재고·시리얼·회원·전체 주문/반품·통계·CSV 관리

## 핵심 업무 규칙
1. 장바구니는 세션 메모리에서 관리하며 `장바구니(n)`의 n은 총 수량 합계다.
2. 비회원 주문은 customer_id가 NULL이며, 외부에 공개하는 무작위 주문번호(order_no)로 조회한다.
3. 회원가입 ID는 이메일 형식으로 저장하며 중복을 허용하지 않는다.
4. 비밀번호는 8~20자, 영문 대문자·소문자·숫자·특수문자를 각각 1자 이상 포함하고 공백은 허용하지 않는다. 저장 시에는 해시만 보관한다.
5. 주문이 성공하면 즉시 CONFIRMED 상태가 된다. 전체 반품만 지원하며 CONFIRMED → RETURNED만 허용한다.
6. 반품 시 재고를 한 번만 복구하고 통계에서 RETURNED 주문은 제외한다.
7. 시리얼 관리 상품은 주문 수량만큼 AVAILABLE product_unit을 배정한다. 반품 시 해당 unit을 다시 AVAILABLE로 돌리고 판매/반품 이력을 남긴다.
8. 상품 조회는 전체 조회와 조건 조회를 분리한다. 조건 조회는 **하위 카테고리 + 가격 범위**를 사용한다.
9. 상품은 하나의 하위 카테고리에 속한다. 카테고리 계층은 category.parent_category_id로 표현한다.
10. 보류 기능(로그인 실패 잠금, 추천인/포인트)은 현재 구현 범위와 DB 스키마에서 제외한다.

## 범위 제외
실제 결제/환불, 배송, 부분 반품, 쿠폰, 다중 창고, 소셜 로그인, 관리자 권한 변경, 로그인 잠금, 추천인/포인트.
